DINING HUB - README

1. WEBSITE STRUCTURE
Dining Hub is a restaurant discovery and reservation website. It helps users browse restaurants, receive restaurant recommendations, register their details, make a reservation and estimate their dining bill.

The assignment folder contains:

- index.html
  The home page. Introduces Dining Hub, explains its services and displays featured restaurants.

- restaurants.html
 Showcases six restaurant listings: Sae Ma Eul BBQ, Sushi Zanmai, Bing ShiFu Mini Bowl, Blackbixon Cafe, HaiDiLao Hotpot and AOI Cafe. Users can view the restaurant links and proceed to make a reservation.

- recommendations.html
  Allows users to select their dietary preference, budget range and dining purpose. The website then displays a restaurant recommendation.

- register.html
  Provides a registration form for users to enter their username, email, phone number, password, gender, dietary preference and country/region.

- reservations.html
  Provides a reservation form where users enter their contact details, select a restaurant, choose a date and time, specify the number of people and select a deposit/payment method.

- bill.html
  Provides a bill calculator. Users select a restaurant, enter the number of people and choose add-ons to estimate the total bill.

- css/style.css
  Contains the CSS styles used to control the website's layout, colours, typography and appearance.

- js/script.js
  Contains the JavaScript functions for form validation, restaurant recommendations, reservation form interactions and bill calculations.

- image/
  Contains the website logo, restaurant images and QR code image.

3. JAVASCRIPT VALIDATION AND FUNCTIONALITY
The JavaScript file is named "script.js". It uses the DOMContentLoaded event to run the page functions after the HTML document has been loaded. Each page function first checks whether its form exists, so the function only runs on the relevant page.

General error handling:
- showError() displays an error message beside a field and adds an invalid CSS class to the field.
- clearAllErrors() clears previous error messages and removes invalid styling before checking the form again.

Recommendation page:
- Checks that the user has selected a dietary preference, budget range and dining purpose.
- Uses if, else if and else statements to match the user's selections with a restaurant.
- Displays the recommended restaurant, estimated price range and deposit amount.
- Creates a "Book Now" link that passes the selected restaurant to the reservation page through the URL.

Registration page:
- Checks that the username has at least five characters and contains only letters, numbers or underscores.
- Checks that the email address follows a basic email format.
- Checks that the phone number contains 8 to 15 digits.
- Requires the password to have at least 10 characters, including an uppercase letter, a lowercase letter, a number and a special character.
- Checks that the confirmation password matches the password.
- Checks that the user has selected a gender, dietary preference and country/region.
- Submits the form when all JavaScript checks pass.

Reservation page:
- Sets the minimum reservation date and time to the current date and time.
- Uses a list of restaurant deposit amounts to update the deposit when a restaurant is selected.
- Reads the restaurant value from the URL so a restaurant selected on the recommendation page can be pre-filled.
- Shows or hides the relevant fields depending on whether the user chooses a voucher or online payment, and depending on the selected online payment type.
- Copies the reservation email into the billing email field when the "same as email" checkbox is selected.
- Checks the user's name, email, phone number, restaurant, reservation date and time, number of people, deposit/payment details and billing email before submission.
- Displays error messages and focuses the first invalid field when the form contains an error.

Bill calculator page:
- Uses predefined average prices for each restaurant.
- Calculates the estimated amount using the selected restaurant price, number of people and add-on price.
- Multiplies the subtotal by 1.10 and then by 1.06 for the additional charges included in the calculation.
- Displays the estimated total in Malaysian Ringgit (RM).

4. KNOWN ISSUES AND LIMITATIONS
- Restaurant recommendations are based on fixed conditions written in JavaScript. They are not generated by an AI system and may not cover every user's preferences.
- Restaurant prices and deposit amounts are predefined estimates. Actual prices and deposit requirements may differ.
- The bill calculator provides an estimate only. The final amount may differ from the restaurant's actual bill.
- Card number validation checks the number of digits only. It does not verify the card with a bank or payment provider.
- The voucher, card and DuitNow options are front-end demonstrations. The website does not process an actual payment.
- The registration and reservation forms are configured to submit to the Swinburne COS10005 test form endpoint. They do not connect to a custom database or account-management system.
- The "same as email" checkbox copies the reservation email when the checkbox is changed. If the reservation email is edited afterwards, the billing email may need to be updated manually.
- The website requires a browser with JavaScript enabled for the recommendation, form validation, interactive reservation fields and bill calculator to work.
